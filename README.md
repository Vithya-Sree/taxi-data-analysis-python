# Taxi Data Analysis Using Python

## Overview

This assignment focuses on cleaning, analyzing, and visualizing taxi trip data using Python. The Seaborn taxis dataset is used to explore fare, distance, payment methods, and customer travel patterns.

## Objectives

* Load and explore the taxi dataset using Pandas.
* Identify and handle missing values.
* Perform exploratory data analysis.
* Visualize taxi fare and distance patterns.
* Analyze payment methods and pickup boroughs.
* Identify relationships between numerical variables.
* Extract meaningful insights from the data.

## Tools and Libraries

* **Python** – Programming language
* **Pandas** – Data cleaning and analysis
* **Matplotlib** – Data visualization
* **Seaborn** – Statistical visualization

## Tasks Performed

### 1. Data Loading

Loaded the taxis dataset using Seaborn and explored its structure, columns, and dimensions.

### 2. Data Cleaning

* Identified missing values.
* Imputed missing numerical values using the median.
* Imputed missing categorical values using the mode.
* Removed records with missing essential timestamps.
* Verified the cleaned dataset.

### 3. Data Visualization

**Matplotlib:**

* Line chart – Fare over time
* Bar chart – Total fare by pickup borough
* Pie chart – Payment method distribution
* Histogram – Trip distance distribution
* Box plot – Tip distribution by pickup borough

**Seaborn:**

* Count plot – Trips by pickup borough
* Scatter plot – Distance versus fare
* Heatmap – Correlation between numerical variables
* Pair plot – Relationships between numerical variables by pickup zone
* Violin plot – Fare distribution by payment method

## Key Areas of Analysis

* Fare and distance patterns
* Trip distribution across boroughs
* Payment method preferences
* Tip distribution
* Relationships between fares, tips, tolls, and total amounts

## Conclusion

This assignment demonstrates how Python can be used to clean, analyze, and visualize real-world taxi data. The visualizations help explore trip patterns, fare distributions, payment methods, and relationships between numerical variables.
